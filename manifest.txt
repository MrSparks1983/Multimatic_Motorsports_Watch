NOTES=Vehicle Gateway BLE connection release based directly on v1.8.31. Selecting MM-CAN-GW in Settings > Bluetooth now starts a real ESP32-S3 BLE central connection instead of only saving the target name/MAC. The watch validates the Multimatic Vehicle Gateway service UUID before reporting CONNECTED, reflects CONNECTING/CONNECTED state in Settings, retries an unexpected dropped gateway link while the target remains selected, and explicitly disconnects the client on Forget Gateway or Bluetooth OFF. The BLE client role coexists with the existing Watch Manager peripheral role and BF1 scanner on the same BLE stack. v1.8.31 active device-name discovery, v1.8.30 soft-off stability, companion GATT UUIDs, OTA, BF1 decoding, A106 telemetry, UI and power behavior are otherwise retained. This release establishes and validates the gateway link; raw vehicle signal decoding on the watch is not changed yet.
